Guided Gameplay Definition

Milestone 4.0H replaces several raw ES2 identifier fields in Hero Data → Gameplay Definition with guided controls. A first-time hero author can now choose known game definitions without already knowing the XML identifiers for affinity, class, politics, ship design, or starting skills.

Load gameplay choices

The first time you use the new selectors, choose Load ES2 choices… in the Gameplay Definition card.

On desktop, Hero Studio can search the standard Endless Space 2 Steam installation locations or let you select the game installation/Public data folder manually. The scan is read-only. It looks for hero affinity, class, politics, ship-design, and English localization data and stores a small local catalog for later use.

In the browser edition, choose the ES2 Public folder or the relevant XML files. Browser-selected files are read locally and are not uploaded.

After the catalog is available, the card provides:

  • Hero Affinity — dropdown populated from indexed hero-affinity definitions.
  • Class — dropdown populated from indexed hero-class definitions.
  • Politics — dropdown populated from indexed hero-politics definitions.
  • Ship Design — searchable dropdown populated from indexed ship-design definitions.

Hero Studio displays beginner-friendly labels in Basic Mode while storing the exact ES2 internal identifier required by generated XML. Advanced Mode additionally exposes the stored IDs. For politics, Hero Studio can fall back to the standard Industrial, Scientist, Pacifist, Ecologist, Religious, and Militarist labels when localization data is unavailable. Ship Design discovery prefers hero-oriented ship-design definitions so the selector does not become cluttered with unrelated fleet designs.

Older, custom, and unavailable references

Opening an existing project must never silently rewrite its gameplay definitions. If a saved value is not found in the currently indexed ES2 data, Hero Studio keeps it as Custom / unavailable reference and shows a warning. This can occur when:

  • the project depends on another mod;
  • the project was created against different game/DLC data;
  • the local gameplay catalog is incomplete; or
  • the author intentionally uses a custom definition.

The value changes only when you deliberately choose another option.

Starting Skills

Starting Skills are the skills the hero already possesses when entering play. They are separate from the later progression choices arranged in the Skill Tree.

Choose Choose Starting Skills… to open the searchable checkbox picker. The picker combines:

  • existing ES2 skills from the locally indexed ES2 Skill Catalog;
  • custom skills authored in the current Hero Studio project; and
  • older/custom starting-skill IDs already stored in the project but not currently resolvable in either source.

Existing unavailable IDs remain selected until you deliberately uncheck them, so loading a catalog never destroys a dependency-provided or older project reference.

The complete Starting Skills change is saved as one Undo/Redo action.

Refreshing data

Choose Refresh choices after an ES2 update, DLC/content change, or game reinstall. Refreshing the local catalog does not change values already stored in a Hero Studio project.

The ES2 Skill Catalog has its own refresh controls because skill discovery and gameplay-definition discovery are stored as separate local indexes.

Export behavior

4.0H changes how values are selected, not the XML structure. Hero Studio continues to write the exact stored values to HeroDefinitions.xml, including each selected Starting Skill as a <Skill Name="..." /> reference.

Project schema remains version 7. Existing .hsproj files continue to open without migration, and manually entered values from earlier milestones remain preserved.

Release Preflight remains the final authority for export readiness. A definition appearing in the local catalog confirms that Hero Studio found it in the indexed game data; it does not guarantee every unusual combination of faction, class, politics, ship, DLC, or dependency will behave as intended in all game states.
