Starter Hero Structures

Starter Hero Structures are optional, guidance-only frameworks for planning an ES2 hero Skill Tree. They make the structure choice from the Create Hero wizard useful after creation without generating skills, prerequisites, Starting Skills, effects, or gameplay values.

Open the guide

In Skill Tree, choose Starter structure. The panel shows the saved guide, all four available frameworks, a guidance-only preview, the real tree evidence currently present, and the next structural decision suggested by the selected framework.

The four structures

Fleet Commander

Starts with a clear Tier 1 entry foundation, develops multiple early fleet-oriented choices, and then encourages deliberate later focus. The guide asks the author to decide which real skills express command, defense, mobility, combat, or another fleet concept.

Governor / Administrator

Starts with a system-facing foundation, develops parallel system-oriented choices, and then encourages later specialization where appropriate. The framework can support industry, economy, science, influence, population, or other system-focused ideas without selecting those skills for you.

Balanced Generalist

Uses a two-part early foundation and complementary branches, with optional later convergence. It is intentionally neutral: the guide helps the author keep broad ideas legible without claiming that a mixed-role hero is better or worse than a specialist.

Advanced Blank Hero

Defines no tier targets. Use it when the structure should remain entirely creator-defined while still keeping the optional guided-creation metadata available.

What the comparison means

The guide counts real Skill Tree nodes and prerequisites already in the project. For structured profiles, each stage reports whether enough real skills are currently represented at the referenced tier. Exceeding a guide minimum is not an error and failing to match a starter shape does not block anything.

The panel also reports current real-skill count, prerequisite count, entry count, and highest tier. These are descriptive signals only. Use Check progression for deeper reachability, gateway, endpoint, tier-order, and prerequisite-route analysis.

Switching structures

Choose another framework and select Use this structure as guidance. Hero Studio updates optional guidance metadata only. It does not change:

  • Hero Class, Affinity, Politics, or Ship Design;
  • Starting Skills;
  • Skill Tree nodes or prerequisites;
  • custom or existing ES2 skill definitions;
  • effects;
  • artwork, localization, dependencies, or release settings.

This makes switching safe even after substantial authoring work.

Relationship to the Create Hero wizard

Step 4 of Create Hero now previews the selected framework before the hero is created. The actual Skill Tree remains empty until the author selects existing ES2 skills or creates custom skills. After creation, the same selected framework is available from Skill Tree for comparison with the real tree.

Authority and compatibility

Starter structures describe shape, not balance. They do not claim an optimal build and do not replace Check progression, Project Health, or Release Preflight. Milestone 4.0M keeps project schema version 7 and the current one-hero-per-export policy.
