ES2 Hero Studio 4.1E Release Notes

Version: 0.4.1-beta.5 Milestone: 4.1E — Catalog Integration Project schema: 8

Added

  • Add from ES2 catalog directly inside the active Generic, Class, or Racial Skill Tree.
  • Tree-role-specific eligibility instead of treating hero-wide eligibility as sufficient for every tree.
  • Direct insertion of existing ES2 skill references into the selected canonical schema-8 tree.
  • Clear blocking for known wrong-tree and direct-only assignments.
  • Non-blocking Needs data handling when local XML evidence is incomplete.
  • Preservation of source tree-role, HeroClass/HeroAffinity, direct-assignment, SkillLevel, and MasteryLevel metadata on native catalog references.

Unchanged safeguards

  • ES2 game data is read locally and remains read-only.
  • The two Innate slots remain separate from tree placement.
  • Legacy schema-7 authored tree data remains preserved and unassigned when its role is unknown.
  • Project schema remains 8.
  • Final schema-8 export reconciliation remains 4.1F.
