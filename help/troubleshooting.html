Troubleshooting

The unsigned app will not open

Control-click or right-click the app in Applications and choose Open. Approve the prompt. Do not disable Gatekeeper globally.

A blank window appears

  1. Close the app.
  2. Reopen it.
  3. Open Help → Show Main Process Log.
  4. Copy Runtime Diagnostics if the interface opens.
  5. Include the log and version in a beta issue, after checking that the material contains no private information.

The global error boundary should display a recovery screen instead of leaving an entirely blank renderer after most interface failures.

A project will not open

Hero Studio checks rotated pre-save backups when the saved project is damaged. A recovered backup opens as unsaved. Use Save As… and do not overwrite the damaged original until the recovered content has been reviewed.

Unsaved work is missing

Open Settings → Recovery Center. Review Latest autosave and Previous autosave. Restore the most recent valid snapshot, then save it as a project file.

Saving fails

Check:

  • destination permissions;
  • available disk space;
  • whether the file is locked by another application;
  • whether the destination drive is connected; and
  • whether the path is writable.

Try Save As… to a local folder such as Documents.

Export fails

Run Release Preflight and resolve blockers. For filesystem errors, choose a local writable destination. Failed clean-folder exports should not leave a half-built package; temporary staging material is cleaned up or rolled back.

Images fail validation

Confirm PNG format and required dimensions. Reimport the original source into Asset Studio and use crop/resize rather than renaming a non-PNG file.

Face or object detection is unavailable

Automatic detection requires network access to load MediaPipe runtime/model files from approved external hosts. Manual crop and positioning remain available without detection.

An imported mod looks different

Open XML Diff & Import Safety. Review semantic changes, unsupported files, preserved XML, and snapshot warnings. Third-party XML may not contain all editor-only information used by Hero Studio.

Where files are stored

Open Help → Open Application Support Folder for preferences, recovery snapshots, recent-project information, and logs. Your .hsproj and exported ZIP files remain in locations you selected.
