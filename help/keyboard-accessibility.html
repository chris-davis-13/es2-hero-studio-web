Use Control instead of Command in browser environments where appropriate.

Keyboard navigation

  • Press Tab from the top of the application to reveal Skip to main content.
  • Library cards, locale cards, resize handles, dialogs, and primary controls are keyboard operable.
  • Arrow keys resize supported panel handles; hold Shift for larger increments.
  • Modal focus remains inside the active dialog and returns to the invoking control when the dialog closes.

Screen readers

Workspace changes, validation changes, notifications, operation progress, and blocking errors use live regions. Controls include labels and pressed/expanded state where applicable.

Reduced motion

The visual system respects reduced-motion preferences for nonessential transitions.

Report an accessibility barrier through the beta feedback process with the affected workspace, control, assistive technology, and reproduction steps.
