ES2 Hero Studio Web Beta 0.4.0-beta.15

Release identity

  • Version: 0.4.0-beta.15
  • Milestone: 4.0N
  • Project schema: 7
  • Release type: public browser beta

Highlights

  • Real-time Asset Studio positioning with frame-synchronized drag and wheel previews
  • Starter Hero Structures with guidance-only previews, real-tree comparison, author decision prompts, and safe metadata-only switching
  • Artwork Requirement Guidance with per-output source-fit, crop enlargement, framing, package-path, and next-action explanations
  • Skill Tree Progression Guidance with entry branches, shortest path explanations, gateway skills, endpoints, disconnected islands, and preserved tier/reachability review
  • Relationship-Aware Recommendations for the active hero, with advisory evidence across Class, Affinity, Politics, Ship Design, direct skills, Skill Tree content, and configured effects
  • Static browser release deployable to GitHub Pages, Cloudflare Pages, Netlify, or another HTTPS static host
  • Official ES2 Hero Studio branding and installable web-app manifest
  • IndexedDB latest/previous recovery snapshots with legacy localStorage migration
  • Recovery snapshot download
  • Direct project file saving where the browser grants access
  • Download-based saving fallback everywhere else
  • Reopenable recent browser files where persistent handles are supported
  • Validated ES2 ZIP generation in the browser
  • Capability-aware clean-folder export
  • Browser compatibility and local-processing status bar
  • Optional persistent-storage request
  • Installable/offline application shell
  • Manual GitHub Pages deployment workflow
  • Verified web-release package and checksums

Important limitations

  • Browser recovery can be removed with site data and is not a substitute for downloaded project backups.
  • Direct file and directory access varies by browser.
  • One hero per exported mod package remains the current beta release policy.
  • Automatic face/object detection may require external MediaPipe resources.
  • No account, cloud synchronization, collaborative editing, or direct Steam Workshop upload is included.
  • A native Windows package remains deferred while browser compatibility is evaluated.

Privacy

Hero project content is processed locally. The hosted app contains no analytics, advertising, or project-upload service. Optional image-detection resources are documented separately.
