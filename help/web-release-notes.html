ES2 Hero Studio Web Beta 0.4.1-beta.6

Release identity

  • Version: 0.4.1-beta.6
  • Milestone: 4.1F
  • Project schema: 8
  • Release type: public browser beta

4.1 highlights

  • Complete Hero Skill System with exactly two Innate assignments and independent Generic, Class, and Racial trees
  • Relationship-aware Generic/Class/Racial skill eligibility from locally indexed ES2 HeroDefinitions
  • Multi-affinity racial relationship support
  • Dedicated two-slot Innate Skill workflow
  • Three-Tree Workspace for canonical schema-8 authoring
  • Local ES2 Skill Catalog placement directly into the selected canonical tree
  • Schema-8 release readiness and XML generation
  • Explicit reconciliation controls for migrated schema-7 legacy tree/direct data
  • Canonical-tree-aware release preflight, validation, references, localization, search, and shared-skill maintenance

Browser capabilities

  • Static HTTPS release published through separate public chris-davis-13/es2-hero-studio-web
  • Private es2-hero-studio source/development repository remains separate from hosted browser files
  • Official branding and installable web-app manifest
  • IndexedDB recovery snapshots and recovery download
  • Direct project-file saving where browser permissions support it
  • Download-based saving fallback
  • Validated ES2 ZIP generation in the browser
  • Capability-aware clean-folder export
  • Installable/offline application shell
  • Verified web-release package, manifest, and checksums
  • Real-time Asset Studio positioning
  • Guided creation, readiness, progression, artwork, relationship, template, and starter-structure workflows

Local ES2 game-data access

The browser cannot silently inspect an installed game. Users select the relevant ES2 Public folder or XML files. Parsing and catalog storage remain local.

The browser edition never modifies installed Endless Space 2 files and does not upload selected game data.

Important limitations

  • Browser recovery can be removed with site data and is not a substitute for downloaded backups.
  • Direct file and directory access varies by browser.
  • One hero per exported mod package remains the beta release policy.
  • Automatic image detection may require external MediaPipe resources.
  • No account, cloud synchronization, collaborative editing, or direct Steam Workshop upload is included.
  • A native Windows package remains deferred while browser compatibility is evaluated.

Privacy

Hero project content is processed locally. The hosted app contains no analytics, advertising, or project-upload service.

Only generated static browser-release files belong in the public web repository; private source, projects, installed-game XML, credentials, and signing material remain outside it.
