Import Review and XML safety

Review before applying

Choose Review Import ZIP rather than replacing the open project directly. Hero Studio analyzes the archive, identifies recognized files, preserves unsupported content where possible, and compares source XML with regenerated XML.

The current project remains unchanged until Apply Reviewed Import is selected.

Hero Studio snapshots

ZIPs created by Hero Studio include HeroStudioProjectSnapshot.json. A valid snapshot restores editor-only data such as prerequisite edges, guided-effect metadata, stable IDs, localization structure, dependency catalogs, external references, and release settings.

Image bytes are rehydrated from the packaged PNG files rather than duplicated inside the snapshot.

Third-party ZIPs

When no valid Hero Studio snapshot exists, the XML importer reconstructs the project from recognized ES2 files. Unsupported files are listed for preservation or review.

A malformed snapshot produces a warning and falls back to XML import rather than being trusted.

Semantic comparison

XML formatting differences do not necessarily represent game-data changes. Semantic comparison normalizes XML structure so whitespace-only changes can be separated from meaningful additions, removals, and modifications.

Undo and restoration

Applying a reviewed import is a single Undo/Redo operation. Hero Studio also retains a pre-import project snapshot for explicit restoration.

Save a separate .hsproj copy before importing complex third-party mods.
