ES2 Hero Studio 4.0M — Starter Hero Structures

  • Version: 0.4.0-beta.14
  • Milestone: 4.0M
  • Project schema: 7

What changed

4.0M completes the planned guided-authoring sequence by turning the non-binding starter profiles introduced in 4.0I into persistent, explainable Skill Tree frameworks.

  • Added a Starter structure panel to the existing Skill Tree workspace.
  • Preserved Fleet Commander, Governor / Administrator, Balanced Generalist, and Advanced Blank Hero.
  • Added guidance-only stage previews and author decision prompts for each structure.
  • Added comparison between each framework and the real nodes already present in the active hero Skill Tree.
  • Added current skill, prerequisite, entry-point, and highest-tier context.
  • Added a next structural action based on the selected framework.
  • Added safe post-creation switching that updates guidance metadata only.
  • Expanded Step 4 of Create Hero with a structure preview before creation.
  • Added Learning Center, bundled Help, desktop package, and browser package documentation.

Deliberate safeguards

Starter Hero Structures remain non-binding. They contain no predefined Skill Tree nodes or edges and never manufacture fake skills. Choosing or switching a structure does not alter gameplay fields, Starting Skills, skill definitions, Skill Tree content, effects, or exports.

Structure-stage minimums are descriptive guideposts rather than validation rules. Matching a framework is not a balance claim, and diverging from one is not an error. Check progression remains the detailed structural-analysis workflow and Release Preflight remains the export authority.

Compatibility

Project schema remains version 7. Existing beta.12 projects open without migration, and existing guided profile metadata continues to resolve to the same four starter profile identifiers and names. The current one-hero-per-export policy remains unchanged.
