ES2 Hero Studio 0.4.0-beta.4

Public desktop beta

This release is the first documented public macOS beta of ES2 Hero Studio. It combines the complete hero-authoring workflow with release validation, lossless Hero Studio reimport, recovery safeguards, production packaging, and official application branding.

Highlights

  • Guided Basic mode and technical Advanced mode
  • Hero Library and resizable Hero Data sections
  • Asset Studio for all four required PNG formats
  • Shared Skill Library and guided effect templates
  • Visual Skill Tree with prerequisites and starting skills
  • Multi-locale authoring and fallback review
  • Dependency declarations and external-reference mapping
  • Non-destructive ZIP import review and semantic XML comparison
  • Project Health, Validation Console, and Release Preflight
  • Validated ZIP and transactional clean-folder export
  • Embedded HeroStudioProjectSnapshot.json for lossless reimport
  • Atomic desktop saves and rotated pre-save backups
  • Latest/previous autosave Recovery Center
  • Save/Discard/Cancel protection on application close
  • Production Electron build without a Vite server
  • Official ES2 Hero Studio icon and public documentation set

Release identity

  • Version: 0.4.0-beta.4
  • Milestone: 4.0D
  • Project schema: 7
  • Application identifier: com.chrisdavis.es2herostudio
  • Primary package: unsigned Apple Silicon DMG and ZIP

Important limitations

  • one hero per exported mod package;
  • unsigned macOS beta;
  • no direct Steam Workshop upload;
  • no public browser edition yet;
  • no native Windows package; and
  • automatic image detection requires network access for MediaPipe resources.

Read Known-Limitations.md before distributing projects or release packages.
