ES2 Hero Studio 0.4.0-beta.14

Public desktop and browser beta

ES2 Hero Studio is a dedicated authoring environment for creating and maintaining Endless Space 2 hero mods. Beta.14 republishes the completed 4.0 guided-authoring sequence under a new immutable release identity while preserving the existing schema-v7 project format and non-destructive authoring model.

The beta is available as an unsigned Apple Silicon macOS application and as a browser edition designed for static HTTPS hosting, offline-capable use, and local project processing.

Highlights

  • Guided Basic mode and technical Advanced mode
  • Hero Library with artwork thumbnails and resizable Hero Data sections
  • Asset Studio for all four required PNG outputs
  • Advisory artwork requirement and source-fit guidance
  • Shared Skill Library and guided effect templates
  • Visual Skill Tree with prerequisites, Starting Skills, and progression analysis
  • Relationship-aware authoring recommendations
  • Starter Hero Structures for Fleet Commander, Governor / Administrator, Balanced Generalist, and Advanced Blank Hero
  • Guidance-only starter structures that never create skills, prerequisites, effects, or gameplay values automatically
  • Guided Create Hero workflow with Hero Readiness recommendations
  • ES2 Skill Catalog with searchable guided selection of existing game skills
  • Guided gameplay selectors for affinity, class, politics, ship design, and Starting Skills
  • Reusable skill, effect, and selected-branch templates
  • Searchable Learning Center, contextual guidance, and glossary
  • Multi-locale authoring and fallback review
  • Dependency declarations and external-reference mapping
  • Non-destructive ZIP import review and semantic XML comparison
  • Project Health, Validation Console, and Release Preflight
  • Validated ZIP and transactional clean-folder export
  • Embedded HeroStudioProjectSnapshot.json for lossless Hero Studio reimport
  • Atomic desktop saves and rotated pre-save backups
  • Latest/previous autosave Recovery Center
  • Save/Discard/Cancel protection on application close
  • Production Electron build without a Vite development server
  • Official ES2 Hero Studio branding and bundled documentation
  • Browser public beta with IndexedDB persistence, recovery history, local file workflows, installable PWA support, and offline application shell

Beta.14 guided-authoring release

Milestones 4.0J through 4.0M complete the guided-authoring sequence introduced earlier in the public beta:

  • 4.0J — Relationship-Aware Recommendations: contextual guidance based on the active hero, skills, and related authoring data.
  • 4.0K — Skill Tree Progression Guidance: explainable paths, progression islands, gateways, Starting Skill coverage, and structural review.
  • 4.0L — Artwork Requirement Guidance: per-output source-fit, crop, enlargement, framing, and next-action guidance without making artistic-quality judgments.
  • 4.0M — Starter Hero Structures: persistent, explainable Skill Tree frameworks that compare guidance with the creator's real tree while remaining fully non-destructive.

Release identity

  • Version: 0.4.0-beta.14
  • Milestone: 4.0M
  • Project schema: 7
  • Application identifier: com.chrisdavis.es2herostudio
  • Desktop package: unsigned Apple Silicon DMG and ZIP
  • Browser package: static HTTPS web application with local-first project storage

Existing schema-v7 beta projects remain compatible with beta.14.

Important limitations

  • one hero per exported mod package;
  • unsigned macOS beta;
  • no direct Steam Workshop upload;
  • no native Windows package at this time;
  • browser security prevents direct installed-game scanning, so browser game-data acquisition uses user-selected local files; and
  • Starter Hero Structures and other guided systems provide recommendations rather than automatically making authoring or balance decisions.

Read Known-Limitations.md before distributing projects or release packages.

Browser edition

The browser edition is now publicly available alongside the desktop beta. It keeps project processing local to the browser, supports persistent browser recovery, and can operate offline after the application shell has been cached.

The desktop edition remains the preferred environment when direct local-file integration with an installed copy of Endless Space 2 is required.
