ES2 Hero Studio 0.4.0-beta.7

Milestone 4.0G — ES2 Skill Catalog and Guided Skill Selection

Milestone 4.0G makes existing Endless Space 2 skills discoverable inside Hero Studio. New hero authors no longer need to memorize skill names or internal XML identifiers before they can build a useful Skill Tree.

Added

  • Searchable Add Existing ES2 Skills picker with checkbox multi-selection.
  • Desktop read-only indexing of the installed Endless Space 2 Public game data, including automatic installation discovery and a manual folder chooser fallback.
  • Browser-side folder/XML selection for building the same catalog without uploading game files.
  • Local catalog cache with refresh and clear controls.
  • Search across names, IDs, descriptions, class/faction associations, and source skill trees.
  • Universal, Class, Faction, and Other ES2 scope filters.
  • Available, Assigned, and Custom ID Conflict status filters.
  • Existing ES2 skill details with source-tree and source-file information.
  • es2-native reference-only skill metadata preserved in schema-v7 projects.
  • Native-skill support in Skill Tree branch templates.
  • Learning Center topics and glossary entries for the ES2 Skill Catalog and existing game-skill references.
  • npm run test:4.0g regression coverage.

Changed

  • Version advanced to 0.4.0-beta.7 and milestone marker to 4.0G.
  • Complete beta regression suite expanded to 17 checks.
  • Existing ES2 skills are no longer regenerated as custom HeroSkillDefinition, simulation-descriptor, GUI, or localization entries.
  • Cross-file validation accepts explicitly declared existing ES2 skill references while continuing to reject unresolved custom references.
  • Skill validation no longer warns that an existing ES2 skill has no Hero Studio-authored effects.
  • Existing ES2 skills are read-only for game-owned IDs and effects; tier and prerequisite layout remain editable.
  • Skill Library now separates Browse Existing ES2 Skills… from creating a custom skill.
  • Bundled help expanded to 23 pages.
  • Project schema remains version 7.

Still deliberately excluded

Milestone 4.0G does not add:

  • multi-hero package export;
  • installed-mod comparison;
  • one-click mod installation; or
  • automatic mod-version bumping.

The validated export policy remains one hero per mod package.

Catalog freshness

Hero Studio intentionally indexes the user's own installed ES2 game data instead of bundling a fixed master list. Refresh the catalog after ES2 updates or changes to installed game content. Browser users should re-import the selected Public data when their game installation changes.
