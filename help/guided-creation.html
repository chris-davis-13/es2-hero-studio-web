Guided Creation Experience

Milestone 4.0I refines the beginner experience around three questions: What does this mean? What should I choose? What should I do next? The new guidance is optional and advisory. It does not replace Project Health, XML validation, or Release Preflight.

Optional six-step Create Hero wizard

Choose Create Hero to open the guided workflow:

  1. Identity & presentation — name, description, and an optional knowledge profile.
  2. Gameplay role — review editable affinity, class, politics, and ship-design recommendations.
  3. Starting skills — decide whether to review the searchable Starting Skills picker immediately after creation or later.
  4. Skill progression — choose a non-binding starter structure such as Fleet Commander, Governor / Administrator, Balanced Generalist, or Advanced Blank Hero.
  5. Artwork — review the four required ES2 image outputs and decide whether to prepare artwork next.
  6. Review — confirm the starting choices and create the hero.

The wizard stores its structural recommendation as guidance metadata. It does not create fake placeholder skills or lock the hero to a faction profile.

Hero Readiness

Project Home now shows Hero Readiness, a seven-area checklist:

  • Hero identity
  • Gameplay profile
  • Starting skills
  • Skill progression
  • Hero artwork
  • Visible text / localization
  • Release readiness

Readiness distinguishes between:

  • Ready — the guided area has enough information to continue.
  • Needs attention — an important authoring area is incomplete.
  • Review — a recommendation worth checking, but not necessarily an export blocker.

The Next button opens the most useful unfinished workspace. Release Preflight remains the authority on whether a package can be exported.

Context-aware recommendations

Project Home can surface recommendations derived from the active hero, including:

  • a Starting Skill that is not represented in the Skill Tree;
  • a Skill Tree with no Tier 1 entry point;
  • gameplay choices that differ from the selected faction guidance profile; and
  • skill themes associated with the selected knowledge profile.

These recommendations are deliberately non-blocking. An unusual combination may be exactly what the mod author intends.

Check Skill Tree progression

In Skill Tree, choose Check progression. Hero Studio explains:

  • how many skills are reachable from the current entry points;
  • whether Starting Skills are represented in the tree;
  • higher-tier skills with no prerequisite;
  • prerequisite links that move to the same or an earlier tier;
  • prerequisite links that skip one or more tiers; and
  • skills that may be unreachable from the current starting/Tier 1 path.

Use Show skill to jump to an affected node. This is structural guidance, not a game-balance rule.

Guided artwork requirements

Hero Asset Studio now places the required output sizes beside the source-image workflow:

  • Large — 360 × 180
  • Medium — 180 × 240
  • Mood — 1324 × 712
  • Mod Icon — 430 × 430

Milestone 4.0L expands this into Artwork Requirement Guidance. Choose Review artwork requirements to see the required package path, current-crop source enlargement, approximate framing pressure, output status, and a suggested next action for each of the four outputs. These cues are advisory; the existing asset validator and Release Preflight remain authoritative for blocking export issues.

Starter structures

The Create Hero wizard includes four structural starting points:

  • Fleet Commander
  • Governor / Administrator
  • Balanced Generalist
  • Advanced Blank Hero

These still create no fake Skill Tree nodes or prerequisites. Milestone 4.0M adds a guidance-only preview to Step 4 and makes the selected structure available later from Skill Tree → Starter structure. There you can compare the framework with real skills already in the tree, review author decisions, and safely switch structures. Switching changes optional guidance metadata only; the actual Skill Tree, Starting Skills, gameplay fields, definitions, and effects remain untouched. See Starter Hero Structures.

Compatibility

4.0I keeps project schema version 7. Existing .hsproj files require no migration. Guided metadata is optional, and existing hero definitions, templates, ES2 catalog references, exports, recovery snapshots, and browser projects remain compatible.

4.0J — Relationship-Aware Recommendations

4.0J extends the 4.0I Hero Readiness experience with active-hero relationship guidance. It compares existing metadata, direct skills, Skill Tree evidence, configured effects, and gameplay contexts, then surfaces advisory connections and tensions without modifying the project or claiming authoritative balance. The existing 4.0I Hero Wizard remains unchanged.

4.0K — Skill Tree Progression Guidance

4.0K deepens the existing Check progression workflow instead of adding a second checker. The panel now explains entry branches, shortest prerequisite routes, shared gateway skills, terminal endpoints, disconnected progression islands, Starting Skill coverage, and the earlier tier/reachability findings in one place. Explain a skill path answers “How do I reach this?” for any node without changing the tree. Gateway and endpoint summaries describe structure rather than balance; unusual trees remain allowed.

4.0M — Starter Hero Structures

4.0M turns the previously stored starter-profile choice into persistent Skill Tree guidance. The new panel compares a selected framework with the real tree and recommends the next structural decision without modifying project content.
