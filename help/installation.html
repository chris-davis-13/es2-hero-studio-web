Install the macOS public beta

Supported public-beta package

The primary public desktop beta is the Apple Silicon package:

ES2-Hero-Studio-0.4.0-beta.4-arm64.dmg

Use it on Macs where uname -m reports arm64. An Intel package may be built for assessment, but it should not be advertised until it has been tested on Intel hardware.

Install from the DMG

  1. Download the .dmg release file.
  2. Double-click the DMG.
  3. Drag ES2 Hero Studio into Applications.
  4. Eject the DMG.
  5. Open Applications.
  6. Control-click or right-click ES2 Hero Studio and choose Open.
  7. Confirm the macOS security prompt.

The beta is intentionally unsigned. macOS may block a normal double-click on first launch. Use the right-click Open process rather than disabling Gatekeeper.

Alternative ZIP package

The release ZIP contains the same application bundle. Extract it, move ES2 Hero Studio.app to Applications, then use the right-click Open process.

First launch

On first launch:

  • complete or skip the three-step introduction;
  • choose Basic or Advanced mode;
  • open the example project or create a new project;
  • review Settings → Recovery Center;
  • save a test project before beginning important work.

Updating the beta

  1. Save and close all Hero Studio projects.
  2. Keep your .hsproj files in a separate projects folder.
  3. Replace the old application in Applications with the newer release.
  4. Open the new application using the same first-launch process if macOS asks again.
  5. Open an existing project and review Project Health before exporting.

Project schema v7 remains compatible across the 0.4.0 beta series.

Uninstalling

Move ES2 Hero Studio.app from Applications to Trash. Project files and exported mod ZIPs remain where you saved them.

Application preferences, recent-project history, autosaves, and logs are stored in the application-support folder. Open it through Help → Open Application Support Folder before uninstalling if you need to copy recovery material.
