Relationship-Aware Recommendations

Milestone 4.0J adds the Relationship Advisor to ES2 Hero Studio.

The advisor examines the active hero as a connected design rather than a collection of independent fields. It uses information already present in the project and highlights relationships worth reviewing.

Where it appears

The compact Relationship Advisor bar appears below the normal Workspace Toolbar in hero-authoring workspaces. Select Review relationships for the full recommendation view.

What it can compare

When those values are available, the advisor can consider Class, Affinity, Politics, Ship Design, direct skill references, Skill Tree nodes/categories, configured skill effects, ship/fleet versus system/colony effect contexts, and Level Up Rule references.

Evidence, not prescriptions

Every recommendation is based on project evidence. The advisor may report, for example, that both ship/fleet and system/colony effect contexts are present, or that a hero combines direct skills with a Skill Tree.

Those observations are not balance judgments. Hero Studio does not automatically change any field and does not claim that one Class, Affinity, Politics value, Ship Design, or skill combination is universally correct.

Priorities

Review — missing information limits relationship analysis.

Consider — a relationship or tension is worth comparing with the intended hero concept.

Context — supporting information helps explain the current design.

Navigation and boundaries

Recommendations can link to existing Hero Data, Skill Tree, Skill Library, or Hero Library workspaces using Hero Studio's existing workspace-selection system.

The Relationship Advisor does not replace Project Health, the Validation Console, or Release Preflight. It also does not perform detailed Skill Tree progression coaching; that remains a separate future feature area.
