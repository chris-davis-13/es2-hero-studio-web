Getting started

This walkthrough creates a single-hero mod package using the guided Basic-mode workflow.

Start with the guided Create Hero wizard

Choose Create Hero to work through identity, gameplay role, Starting Skills planning, Skill Tree structure, artwork, and review. The wizard applies editable recommendations only. After creation, Project Home shows Hero Readiness and opens the most useful unfinished area.

1. Start a project

Choose New hero project from the welcome screen. Save early using Save As… and choose a memorable .hsproj filename.

A Hero Studio project is the editable source. It is not the same as the final ES2 mod ZIP.

2. Use Project Home

Project Home tracks six stages:

  1. Hero identity
  2. Gameplay definition
  3. Artwork and assets
  4. Skills and Skill Tree
  5. Localization
  6. Release readiness

Select the recommended next action to move through the workflow.

3. Enter Hero Data

In Hero Data, complete the identity, Gameplay Definition, and package metadata. For Gameplay Definition, choose Load ES2 choices… once to index the local game data, then select affinity, class, and politics from dropdowns and use the searchable Ship Design selector. Existing projects keep older or custom values until you deliberately replace them.

Choose Choose Starting Skills… to select the skills the hero already possesses when entering play. The searchable checkbox picker combines existing ES2 skills with custom skills in the project.

The internal name is used in filenames and XML identifiers. Keep it stable after release whenever possible. See Guided Gameplay Definition.

4. Prepare the four images

Asset Studio requires PNG files at these final sizes:

AssetRequired size
Large360 × 180
Medium180 × 240
Mood1324 × 712
Mod icon430 × 430

Asset Studio can crop and resize source artwork. Inspect the result at full size before accepting it.

Optional face and object detection retrieves MediaPipe model files from approved external hosts. The selected project image remains in the application; it is not intentionally uploaded by Hero Studio.

5. Create skills

Open Skill Library and create reusable skill definitions. Basic mode provides guided effect templates for common operations. Add clear names and descriptions before placing skills in the Skill Tree.

Select Save as Template when a skill will be useful in future projects. Individual effects can also be saved from their effect cards.

6. Build the Skill Tree

Assign skills to tiers, position the nodes, and connect prerequisites. Starting Skills are chosen separately in Hero Data. Project Health reports broken references and circular prerequisites. Select several nodes and choose Save branch to preserve them and their internal prerequisite connections as a reusable template.

If you chose a starter profile in Create Hero, select Starter structure in Skill Tree to compare that optional framework with the real skills you have added. The guide does not create or replace nodes or prerequisites.

Use in-context help

Select Learn at any time to search field explanations, workflow guidance, and the terminology glossary. Question-mark controls beside selected fields open the most relevant topic directly.

7. Review localization

English is the default locale. Add other locales in Localization, review fallback values, and resolve missing required strings.

8. Save and reopen

Save the project, close it, and reopen it. This confirms that the editable project is stored correctly before release work begins.

9. Run Project Health

Resolve blocking findings in Project Health and the Problems panel. Warnings may be acceptable, but each should be understood before release.

10. Run Release Preflight

Open Export & Release Preflight. Confirm metadata, images, localization, dependency declarations, XML validity, and release notes.

The first public beta exports one hero per mod package. A project can contain multiple heroes for authoring, but validated package export is blocked until only one exportable hero remains.

11. Export

Create a validated ZIP for distribution or a clean mod folder for local testing. Keep the .hsproj file as the editable source and the ZIP as the release artifact.

Choose existing ES2 skills without memorizing IDs

In Skill Library, choose Browse Existing ES2 Skills…. The desktop app can index your installed game data read-only; the browser edition lets you select the ES2 Public folder or XML files. Search by name, class, faction, or internal ID, check one or more skills, and choose Add Selected Skills. Use Create custom skill when you want Hero Studio to generate a new skill definition and effects. See ES2 Skill Catalog.
