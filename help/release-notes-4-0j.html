ES2 Hero Studio 4.0J Release Notes

Version: 0.4.0-beta.10 Milestone: 4.0J — Relationship-Aware Recommendations Project schema: unchanged from 4.0I

Purpose

4.0J extends the guided-creation and Hero Readiness foundation from 4.0I by helping authors understand how the active hero's existing choices relate to one another.

The milestone does not add another Hero Wizard. The existing 4.0I wizard remains the creation pathway.

Included

  • Relationship Advisor integrated immediately below the existing Workspace Toolbar in hero-authoring workspaces.
  • Active-hero snapshot covering Class, Affinity, Politics, Ship Design, direct skill references, Skill Tree evidence, configured effects, and Level Up Rule when available.
  • Advisory relationship checks for missing core relationship anchors, Class ↔ Ship Design, Affinity ↔ Politics, metadata ↔ gameplay evidence, direct skills ↔ Skill Tree, gameplay-theme signals, mixed ship/system contexts, broad Skill Tree category mixes, and Level Up Rule context.
  • Evidence chips showing what project data produced each recommendation.
  • One-click navigation to existing Hero Studio workspaces.
  • No automatic project changes.
  • No project-schema migration.

Design boundary

Relationship recommendations are authoring guidance, not validation or game-balance authority. The advisor derives signals from current project fields, names, Skill Tree categories, effect targets, and effect paths. It does not declare a Class, Affinity, Politics value, Ship Design, skill, or effect combination to be the "best" or "correct" choice.

Detailed Skill Tree progression guidance remains outside 4.0J and can be addressed as a later milestone.

Regression coverage

Run npm run test:4.0j.
