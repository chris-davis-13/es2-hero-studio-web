4.0L Release Notes — Artwork Requirement Guidance

Version: 0.4.0-beta.12 Milestone: 4.0L Project schema: 7

Added

  • Expanded the existing Hero Asset Studio guided artwork check into per-output Artwork Requirement Guidance.
  • Added source-fit analysis using the current saved crop and the same cover/zoom geometry as Asset Studio.
  • Added approximate source-enlargement and framing-pressure explanations for Large, Medium, Mood, and Mod Icon outputs.
  • Added per-output package paths, status explanations, and actionable next-step guidance.
  • Added a Review artwork requirements detail panel with direct navigation back to each crop editor.
  • Added Learning Center and bundled documentation coverage for the new artwork guidance.

Preserved

  • The four established output specifications: Large 360×180, Medium 180×240, Mood 1324×712, and Mod Icon 430×430 PNG.
  • Existing Asset Studio crop/generation behavior.
  • Existing validation and Release Preflight authority.
  • Project schema 7 and the one-hero beta export policy.
  • Advisory, non-blocking guidance: 4.0L does not judge artistic quality or automatically alter source artwork, crops, or generated assets.
