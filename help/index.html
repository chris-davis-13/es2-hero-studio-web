ES2 Hero Studio documentation

ES2 Hero Studio is a client-side authoring application for creating, validating, importing, and packaging custom heroes for Endless Space 2.

Example project

The release includes ES2-Hero-Studio-Public-Beta-Example.hsproj. It contains one complete hero, all required images, guided effects, a Skill Tree prerequisite, localization, and release settings. Open it as a safe practice project before working on an important mod.

4.0N — Real-Time Asset Positioning

Hero Asset Studio now previews crop dragging and wheel zoom locally at display-frame cadence, then commits the final crop to project state after the interaction. See Real-Time-Asset-Positioning.md for details.
