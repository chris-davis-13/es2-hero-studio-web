ES2 Hero Studio 0.4.0-beta.8

Milestone 4.0H — Guided Gameplay Definition

Milestone 4.0H removes another major beginner barrier from Hero Data. Affinity, class, politics, ship design, and starting skills can now be selected through guided controls instead of requiring users to know ES2 internal identifiers in advance.

Added

  • Local ES2 Gameplay Catalog for hero affinity, class, politics, and ship-design definitions.
  • Automatic read-only desktop discovery with manual ES2/Public-folder fallback.
  • Browser Public-folder/XML import for the same local gameplay-choice workflow.
  • Dropdown selectors for Hero Affinity, Class, and Politics.
  • Searchable selector for Ship Design.
  • Searchable checkbox-based Choose Starting Skills workflow.
  • Combined Starting Skills source containing existing ES2 catalog skills and custom project skills.
  • Preservation and clear labeling of older, custom, dependency-provided, or currently unavailable references.
  • Beginner-friendly labels in Basic Mode, with Advanced Mode display of the exact stored ES2 gameplay identifier.
  • Politics fallback labels and hero-oriented Ship Design filtering when the game data does not provide a clearer localized label.
  • New Guided Gameplay Definition documentation and Learning Center wording.
  • npm run test:4.0h focused regression coverage.

Changed

  • Version advanced to 0.4.0-beta.8 and milestone marker to 4.0H.
  • Complete beta regression suite expanded to 18 checks.
  • Gameplay Definition no longer requires raw free-text entry for affinity, class, politics, or ship design in the standard guided workflow.
  • Starting Skills no longer requires a comma/newline-separated raw ID textarea.
  • Existing project values remain intact when the current local catalog cannot resolve them.
  • Project schema remains version 7.
  • The one-hero-per-export-package policy remains unchanged.

Safety and compatibility

4.0H changes authoring controls rather than the generated HeroDefinition structure. Existing .hsproj files, imported hero definitions, custom dependency references, and previously typed identifiers continue to be preserved. Catalog scans are read-only and local; Hero Studio does not modify the Endless Space 2 installation while building guided choice lists.

Still deliberately excluded

Milestone 4.0H does not add:

  • multi-hero package export;
  • installed-mod comparison;
  • one-click mod installation; or
  • automatic mod-version bumping.
