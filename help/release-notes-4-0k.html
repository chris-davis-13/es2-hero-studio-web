ES2 Hero Studio 4.0K Release Notes

Release identity

  • Version: 0.4.0-beta.11
  • Milestone: 4.0K
  • Feature: Skill Tree Progression Guidance
  • Project schema: 7

Added

  • Expanded the existing Check progression panel instead of introducing a second progression tool.
  • Added six progression metrics: reachable skills, entry branches, path depth, gateway skills, endpoints, and review findings.
  • Added Explain a skill path for a shortest prerequisite route from current Starting Skill or Tier 1 entry points.
  • Added branch summaries with downstream skill count and maximum branch depth.
  • Added shared gateway detection for non-entry skills that all current paths to multiple later skills pass through.
  • Added terminal endpoint summaries.
  • Added disconnected-island grouping for unreachable connected sections of the tree.
  • Added richer Learning Center guidance and dedicated bundled documentation.

Preserved

  • Existing 4.0I reachability, Starting Skill, higher-tier-root, tier-direction, and tier-gap guidance.
  • Existing 4.0I Create Hero wizard.
  • Existing 4.0J Relationship-Aware Recommendations.
  • Existing Skill Tree validation and Release Preflight authority.
  • Existing project schema version 7 and one-hero export policy.

Guidance policy

Skill Tree Progression Guidance is advisory. It describes graph structure and routes without claiming that a Skill Tree is best, correct, optimal, or balanced. It never changes the project automatically.

Packaging

The 4.0K guide and release notes are registered in the central Help catalog and included in both desktop and browser beta documentation bundles. The desktop documentation list also carries forward the 4.0J relationship guidance that was already present in browser packaging.
