Localization and dependencies

Localization workflow

English is the default locale. Hero Studio builds localization targets for hero names, descriptions, skills, and custom keys.

For each additional locale:

  1. Add the locale.
  2. Filter to missing or changed entries.
  3. Enter translations.
  4. Review fallback values.
  5. Resolve duplicate or invalid keys.
  6. Re-run Project Health and Release Preflight.

CSV import/export can support external translation work. Review imported changes before release.

Fallback behaviour

An untranslated value may fall back to the default locale during authoring. Fallback does not necessarily mean the release is complete. Release Preflight reports missing required localized content according to the project state.

Dependency categories

Required

The mod cannot operate as intended without this dependency.

Optional

The mod can use or integrate with the dependency, but remains usable without it.

Incompatible

The mod should not be used with the named dependency or version range.

External references

Map external XML references to a declared dependency. This allows Hero Studio to distinguish an intentional external reference from an unresolved project reference.

Availability enforcement

The known-mod catalog can record active and inactive dependencies. Availability checks are authoring aids; users must still install the actual required mod in Endless Space 2.
