ES2 Hero Studio 0.4.0-beta.6

Milestone 4.0F — Templates and Contextual Guidance

This release adds two focused usability systems while preserving project schema 7 and the existing desktop/browser export architecture.

Reusable Template Library

  • Local skill, effect, and Skill Tree branch templates
  • Capture from Skill Library, Effect Builder, Skill Tree, or the dedicated Template Library workspace
  • Search, filter, sort, favorite, tag, rename, duplicate, and delete controls
  • Template previews and destination selection
  • Skill-ID conflict analysis with unique-copy, replace, and keep-existing policies
  • Collision-safe branch insertion with relative node layout and internal prerequisite preservation
  • One-action project application with normal Undo and Redo support
  • Portable .hstemplates library export and import
  • Local-first storage with no account or project-upload service

Better in-context learning

  • Searchable Learning Center available from the header and every workspace
  • Contextual guidance for core Hero Data, assets, skills, effects, Skill Tree, localization, dependencies, XML safety, release, browser saving, and recovery
  • Searchable Hero Studio and ES2 terminology glossary
  • Direct field-level help controls
  • Validation-console Explain actions
  • Basic- and Advanced-mode-aware guidance
  • Dismissible workspace tips and a global visibility preference
  • Clear reasons for unavailable template actions

Release identity

  • Version: 0.4.0-beta.6
  • Milestone: 4.0F
  • Project schema: 7
  • Application identifier: com.chrisdavis.es2herostudio
  • Template-library format: hero-studio-template-library, version 1

Deliberate exclusions

Milestone 4.0F does not add:

  • multi-hero package export;
  • installed-mod comparison;
  • one-click mod installation;
  • automatic mod-version bumping;
  • cloud template synchronization; or
  • a community template marketplace.

The one-hero-per-exported-package policy remains unchanged.
