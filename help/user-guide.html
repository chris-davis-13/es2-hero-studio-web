ES2 Hero Studio user guide

Guided creation and Hero Readiness

The optional Create Hero wizard provides six short steps for first-time authors. Project Home then tracks Hero Readiness across identity, gameplay, Starting Skills, Skill Tree progression, artwork, localization, and release preparation. Choose Starter structure in Skill Tree to compare an optional Fleet Commander, Governor / Administrator, Balanced Generalist, or Advanced Blank framework with the real tree without creating anything. Choose Check progression for plain-language reachability and tier guidance. Hero Asset Studio shows the exact required ES2 output sizes and warns when a source is smaller than the largest output. These are guidance features; Release Preflight remains the export authority.

Product purpose

ES2 Hero Studio creates editable hero projects and generates validated Endless Space 2 mod packages. It combines project management, image preparation, skill authoring, localization, XML review, dependency declarations, recovery, and release checks in one application.

Project files and release files

.hsproj

The Hero Studio project file is the editable source of truth. It contains authoring metadata that cannot be represented completely in ES2 XML, including stable IDs, Skill Tree edges, guided-effect metadata, localization structure, dependency information, and release settings.

Validated ZIP

The validated ZIP is the distributable mod package. Hero Studio exports include HeroStudioProjectSnapshot.json, allowing another Hero Studio installation to restore editor-only information when the ZIP is reimported.

Clean mod folder

The clean-folder export writes the package as a folder for local testing. Desktop exports are staged and committed transactionally to reduce partial output after a failure.

Application shell

The header contains project commands, search, Problems, the searchable Learning Center, mode controls, settings, and save status. The Project Explorer organizes workspaces by Create, Review & Export, Advanced, and Developer groups.

Resizable layouts are stored as application preferences, not project data. Reset them through Settings → Reset panel layout.

Hero Library

Use Hero Library to create, duplicate, archive, select, and remove heroes. The first public beta supports authoring multiple heroes but exports one hero per mod package.

Hero Data

Hero Data contains three independently resizable sections:

  • Identity & Localization
  • Gameplay Definition
  • Workshop & Package Metadata

The workspace scrolls as sections grow. Shortened sections receive their own internal scrollbar.

Gameplay Definition uses locally indexed ES2 choices instead of requiring raw identifiers for the normal workflow. Affinity, class, and politics use dropdowns; Ship Design adds search; Starting Skills uses a searchable checkbox picker that combines existing ES2 skills and custom project skills. Values from older projects or dependencies that are not in the current catalog are preserved until deliberately replaced. See Guided Gameplay Definition.

Asset Studio

Asset Studio validates PNG dimensions, crops source artwork, and can generate required variants. Preserve original source artwork outside the project as an additional backup.

Required final sizes are Large 360×180, Medium 180×240, Mood 1324×712, and Mod Icon 430×430.

Choose Review artwork requirements for per-output source-fit, enlargement, framing, package-path, state, and next-action guidance. These are quality/composition cues rather than additional ES2 rules; Release Preflight remains the export authority.

Skill Library and Effect Builder

Skill definitions can be reused across heroes. Guided templates create structured effects without requiring manual XML. Advanced mode exposes Expert XML for content that cannot be represented by a guided template.

Use clear skill IDs and avoid changing published IDs without reviewing references and localization keys.

Template Library

Capture shared skills, individual effect configurations, or selected Skill Tree branches for reuse in another project. Templates are stored locally outside the .hsproj file and can be moved between desktop and browser installations using .hstemplates export and import. Hero Studio previews additions and ID conflicts before applying a template, then records the project change as one Undo command.

Existing ES2 Skill Catalog

Skill Library provides two distinct authoring paths: Browse Existing ES2 Skills… for game-supplied skills and Create custom skill for new Hero Studio-authored definitions. The catalog is built from the user's own ES2 Public data, searched locally, and cached locally. Existing ES2 skills are reference-only: Hero Studio exports their IDs in the custom tree but does not recreate their game-owned effects, GUI, or localization. Their tier and prerequisite connections remain editable. See ES2 Skill Catalog and Guided Skill Selection.

Skill Tree

The Skill Tree controls tiers, node positions, and prerequisites. The hero's Starting Skills are selected in Hero Data and can reference either existing ES2 skills or custom project skills. Use Project Health to detect missing skills, broken edges, and cycles.

Advanced mode includes XML Preview. Its token-aware search supports separate search terms, quoted phrases, case sensitivity, whole-word matching, and match navigation.

Localization

Localization supports multiple locales, per-entry status, fallback review, filtering, and CSV workflows. Required hero and skill strings should be complete before release.

Dependencies

Advanced Dependencies distinguishes required, optional, and incompatible mods. External references can be mapped to a dependency declaration. Release Preflight reports unresolved or unavailable dependencies.

Import Review

Importing an existing mod ZIP is non-destructive. Hero Studio prepares a review, compares source and generated XML, reports unsupported files, and waits for Apply Reviewed Import.

Applying an import is recorded as one project-wide Undo command. A pre-import project snapshot can also be restored.

Recovery

Hero Studio retains latest and previous autosaves. Existing project saves create rotated pre-save backups. Recovery Center can restore or delete snapshots.

A recovered project is marked unsaved and should be saved under a deliberate filename before replacing any damaged source.

Release Preflight

Release Preflight combines project metadata, image validation, localization, dependencies, XML checks, previous-export comparison, file manifest generation, and release reporting.

Do not distribute a package with unresolved blocking findings.

Contextual learning

Select Learn from the header or workspace toolbar to search guidance and the terminology glossary. Field-level question-mark controls open relevant explanations, and Validation Console findings include an Explain action. Workspace tips can be dismissed individually or hidden through Settings without disabling the Learning Center.

Search, Undo, and shortcuts

Use Command+P to open Quick Open and search. Use standard Undo/Redo shortcuts for project-wide editing history. Open the keyboard shortcut reference with the ? control in the application header.

Real-time portrait positioning

Hero Asset Studio now keeps drag movement local to the crop canvas while artwork is being repositioned. The image follows the pointer through frame-synchronized drawing, then the final crop is committed when the drag ends. Wheel zoom behaves similarly. Final generated PNGs still use the original source and existing asset pipeline.
