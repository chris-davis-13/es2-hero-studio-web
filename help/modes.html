Basic and Advanced modes

Basic and Advanced modes change which authoring tools are visible. They do not change project data, project schema, or export output.

Basic mode

Basic mode is recommended for most authoring work. It includes:

  • Project Home;
  • Hero Library;
  • Hero Data;
  • Asset Studio;
  • Skill Library;
  • Template Library;
  • Skill Tree;
  • Localization;
  • Faction Knowledge;
  • Project Health; and
  • Export & Release Preflight.

Guided effect templates are emphasized. Expert XML controls and technical dependency tools remain hidden.

Advanced mode

Advanced mode adds:

  • Advanced Dependencies;
  • XML Diff & Import Safety;
  • Reference Explorer;
  • Dependency Graph;
  • XML Preview beside the Skill Tree; and
  • expert effect/XML controls.

Use Advanced mode when importing an existing mod, preserving unsupported XML, declaring external references, or inspecting generated XML.

Developer Tools

Developer Tools is a separate local preference. It reveals Runtime Diagnostics and troubleshooting controls. It is not a third authoring mode and does not affect exported projects.

Switching modes safely

Switching between Basic and Advanced mode never deletes advanced data. When a project contains advanced content, Basic mode displays a preservation notice rather than hiding the existence of that content completely.

Guidance in both modes

The Learning Center changes results according to the current workspace and hides Advanced-only guidance while Basic mode is active. Field help, validation explanations, and the Template Library are available in both modes. Hiding contextual workspace tips does not remove the searchable Learning Center.
