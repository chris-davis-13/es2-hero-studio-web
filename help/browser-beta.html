Browser public beta

ES2 Hero Studio Web Beta provides the same schema-v7 hero authoring, validation, import review, and validated ZIP export workflow as the desktop beta without requiring an application installation.

Start safely

  1. Open the published HTTPS web address.
  2. Read the Web Beta status bar near the top of the application.
  3. Select New hero project, Open project, or Review mod ZIP.
  4. Download a project copy after meaningful work and before clearing browser data.

Project and image content is processed locally by the browser. Hero Studio does not provide an account, cloud project storage, or a project-upload service.

Saving projects

Browser saving has two possible behaviours:

  • Direct file saving: browsers with the File System Access API can reopen and overwrite a user-approved .hsproj file after permission is granted.
  • Download saving: other browsers download a new .hsproj file. Keep the newest copy in a known folder and select it again with Open when returning.

The application identifies which behaviour is active in the Web Beta status bar.

Browser recovery

The browser edition stores the latest and previous unsaved recovery snapshots in IndexedDB when available. Open Settings → Recovery Center to restore, download, or delete them.

Browser recovery is a convenience, not a replacement for a downloaded project file. Site data may be removed by private-browsing rules, browser cleanup, storage pressure, or user action. Use Download copy in Recovery Center when preserving a recovery snapshot matters.

The Request persistent recovery storage control asks the browser to reduce automatic eviction risk. The browser may still decline the request.

Mod export

Export validated ZIP works in supported browsers and downloads the finished ES2 package.

Direct clean-folder writing is available only when the browser grants directory access. When that capability is unavailable, download the validated ZIP and extract it into the appropriate Endless Space 2 Mods folder.

Offline use

After a successful production load, the web beta installs an offline application shell through a service worker. Core authoring and previously cached workspaces can continue without a network connection.

Automatic face and object detection may still require its external MediaPipe runtime and model resources. Manual crop and image editing remain available when those resources are unavailable.

Install as a web app

Some browsers offer Install web app in the Hero Studio status bar or their own browser menu. Installation creates an app-like launcher but does not change where projects are stored. Continue downloading project backups.

Browser support

The release is designed for current desktop versions of Safari, Chrome, Edge, and Firefox. Capability differences are handled through fallbacks:

  • Chrome and Edge typically support direct project and folder access.
  • Safari and Firefox may use upload/download project saving and validated ZIP export.
  • Private browsing may reduce or remove recovery persistence.

The status bar reports the capabilities actually detected rather than relying only on the browser name.

Privacy summary

Hero project data, selected images, imported ZIPs, generated XML, and export assembly remain in the browser process. Optional automatic image detection downloads code and model resources from the hosts listed in Privacy and Local Processing. No analytics or advertising service is included.

Feedback

When reporting a browser issue, include:

  • browser name and version;
  • operating system;
  • whether the app was opened in a tab or installed mode;
  • the result from Runtime Diagnostics;
  • the action that failed; and
  • whether the problem also occurs with the bundled example project.

Do not share private project files or images unless doing so is necessary and intentional.

Importing the ES2 Skill Catalog

The browser cannot silently inspect an installed game. In Skill Library, choose Browse Existing ES2 Skills…, then select the ES2 Public folder where folder input is supported or select the relevant XML files directly. Parsing and catalog storage remain local to the browser. Re-import the files when the installed game data changes.
