Browser public beta

ES2 Hero Studio Web Beta provides the same schema-8 hero authoring, validation, import-review, and validated ZIP export workflow as the desktop beta without requiring an application installation.

Schema 8 includes exactly two canonical Innate Skill assignments plus independent Generic, Class, and Racial skill trees.

Start safely

  1. Open the published HTTPS web address.
  2. Read the Web Beta status bar.
  3. Select New hero project, Open project, or Review mod ZIP.
  4. Download a project copy after meaningful work and before clearing browser data.

Project and image content is processed locally by the browser. Hero Studio does not provide an account, cloud project storage, or a project-upload service.

Saving projects

Browser saving has two possible behaviours:

  • Direct file saving: browsers with suitable File System Access support can reopen and overwrite a user-approved .hsproj file after permission is granted.
  • Download saving: other browsers download a new .hsproj file.

The Web Beta status bar reports the active capability model.

Browser recovery

The browser edition stores the latest and previous unsaved recovery snapshots in IndexedDB when available. Open Settings → Recovery Center to restore, download, or delete them.

Browser recovery is a convenience, not a replacement for a downloaded project file. Site data may be removed by private-browsing rules, browser cleanup, storage pressure, or user action.

Complete Hero Skill System

The browser edition supports the same local schema-8 skill workflow:

  • exactly two Innate Skill slots;
  • Generic, Class, and Racial Skill Tree workspaces;
  • relationship-aware eligibility;
  • multi-affinity racial relationships;
  • local ES2 Skill Catalog selection;
  • canonical schema-8 release validation; and
  • explicit legacy reconciliation for migrated schema-7 projects.

Mod export

Export validated ZIP downloads the finished ES2 package.

Direct clean-folder writing is available only where the browser grants directory access. Otherwise, use the validated ZIP.

Offline use

After a successful production load, the web beta installs an offline application shell through a service worker. Core authoring and previously cached workspaces can continue without a network connection.

Automatic image detection may still require external MediaPipe resources. Manual crop/image editing remains available without them.

Install as a web app

Some browsers offer Install web app in the Hero Studio status bar or browser menu. Installation creates an app-like launcher but does not change where projects are stored. Continue downloading project backups.

Browser support

The release is designed for current desktop versions of Safari, Chrome, Edge, and Firefox with capability-based fallbacks.

  • Chrome/Edge commonly support broader direct file/directory capabilities.
  • Safari/Firefox may rely more heavily on upload/download workflows.
  • Private browsing may reduce recovery persistence.

Privacy summary

Hero project data, selected images, imported ZIPs, selected local ES2 XML, generated XML, and export assembly remain local to the browser process.

Optional automatic image detection can download the external resources listed in Privacy and Local Processing. No analytics, advertising, or project-upload service is included.

Importing local ES2 catalogs

The browser cannot silently inspect an installed game. Use the local catalog controls to select the ES2 Public folder where supported or select relevant XML files directly. Parsing and catalog storage remain local.

Re-import local ES2 data after game/DLC changes when appropriate.
