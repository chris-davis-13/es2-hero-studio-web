Templates and contextual guidance

Milestone 4.0F adds a local reusable Template Library and in-context learning throughout the authoring workflow. These features improve speed and understanding without changing the project schema or ES2 export format.

Template Library

Open Create → Template Library to capture and reuse authoring work across projects.

Hero Studio supports three template types:

  • Skill templates preserve the skill ID, display name, description, category, tags, and guided or expert effects.
  • Effect templates preserve one complete effect configuration so it can be appended to another shared skill.
  • Tree branch templates preserve selected Skill Tree nodes, relative positions, tiers, starting-skill status, and prerequisite connections between the selected nodes.

Templates are separate from the open .hsproj project. They are stored locally by the current desktop application or browser site until exported.

Capture a template

Capture a skill

  1. Open Skill Library.
  2. Select the skill.
  3. Choose Save as Template.
  4. Enter a clear template name.

The same action is also available from the Template Library's Capture from this project panel.

Capture an effect

Choose Save template on an effect card, or select an effect in the Template Library capture panel. Only that effect configuration is stored.

Capture a Skill Tree branch

  1. Open Skill Tree.
  2. Select one or more nodes.
  3. Choose Save branch.
  4. Name the branch.

Only prerequisite edges whose source and target are both selected are included. Use Save complete tree template in Template Library when the entire tree should be captured.

Preview and apply

Select a template to see its contents and application preview. Hero Studio reports the number of skills, effects, nodes, and prerequisite edges that will be added.

Applying a template changes the project as one undoable action. Template-library maintenance itself—renaming, favoriting, duplicating, importing, or deleting templates—is local application data and is not part of project Undo history.

Skill ID conflicts

When a skill template uses an ID already present in the project, choose one of these policies:

  • Create a uniquely named copy keeps the existing skill and creates a safe suffixed ID.
  • Replace the existing shared skill updates that definition and synchronizes hero nodes that reference it.
  • Keep the existing skill unchanged does not apply the template.

Branch templates always create collision-safe skill IDs. The application preview reports any names that will require remapping.

Organize and move templates

The library supports search, type filters, favorites, tags, sorting, duplication, rename, and deletion.

Choose Export library… to create an .hstemplates file. Import that file in another Hero Studio browser, device, or desktop installation. During import, Hero Studio can replace templates with matching internal template IDs or keep both copies.

Template files contain only captured template data. They do not include project images, unrelated heroes, recovery snapshots, or installed-game files.

Local-storage boundaries

Desktop and browser template libraries are local to their own application storage. They do not synchronize automatically. Use .hstemplates export and import to move a library between environments.

Clearing browser site data may remove the browser's local template library. Keep an exported template-library backup when the templates are important.

Contextual guidance

Select Learn in the application header or workspace toolbar to open the searchable Learning Center. It contains:

  • field and workflow explanations;
  • examples of valid values;
  • ES2 and Hero Studio terminology;
  • Basic- and Advanced-mode guidance;
  • workspace-specific results; and
  • links from validation findings to a relevant explanation.

Question-mark controls beside selected fields open the associated topic directly. Disabled template controls include a reason in their tooltip.

Workspace tips

Each workspace can show a short contextual tip. Dismiss a tip for that workspace using its close control. To show or hide contextual tips globally, use Settings → Show contextual tips.

The complete Learning Center remains available even when workspace tips are hidden.

Validation remains authoritative

Contextual guidance explains concepts and recommended workflows. It does not certify that a value exists in Endless Space 2 or that a package will work in game. Project Health and Release Preflight remain the final application checks, and custom or dependency-provided identifiers may still require in-game testing.
