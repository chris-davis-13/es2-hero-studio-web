ES2 Hero Studio 0.4.0-beta.9

Milestone 4.0I — Guided Creation and Hero Readiness

Milestone 4.0I focuses on the final beginner-facing workflow refinements after the ES2 Skill Catalog and Guided Gameplay Definition. It adds an optional creation wizard, a continuously updated Hero Readiness checklist, context-aware recommendations, plain-language Skill Tree progression analysis, guided artwork requirements, and non-binding starter hero structures.

Added

  • Six-step optional Create Hero wizard.
  • Editable gameplay-profile recommendations during hero creation.
  • Starting Skills planning step that points first-time users to the searchable 4.0H picker.
  • Four starter progression structures: Fleet Commander, Governor / Administrator, Balanced Generalist, and Advanced Blank Hero.
  • Hero Readiness on Project Home with Ready, Needs attention, and Review states.
  • Context-aware suggestions for unusual profile combinations, missing Starting Skills, Starting Skills outside the Skill Tree, and common faction skill themes.
  • Check progression command in Skill Tree.
  • Plain-language progression findings for reachability, entry points, tier order, tier gaps, and higher-tier roots.
  • Show skill navigation from progression findings.
  • Guided artwork source-quality panel with all four exact ES2 output sizes.
  • Learning Center topics for Hero Readiness, the Create Hero wizard, and Skill Tree progression checks.
  • npm run test:4.0i focused regression coverage.

Changed

  • Version advanced to 0.4.0-beta.9 and milestone marker to 4.0I.
  • Complete beta regression suite expanded to 19 checks.
  • Project Home now answers “what should I work on next?” separately from technical validation.
  • New heroes can begin from sensible editable defaults without requiring the author to understand every technical field first.
  • Project schema remains version 7.
  • The one-hero-per-export-package safeguard remains unchanged.

Safety and compatibility

4.0I does not change generated ES2 XML rules or package structure. Guided recommendations do not silently rewrite existing heroes. The progression checker is advisory and does not block unusual Skill Trees. Artwork guidance reports source-size tradeoffs without preventing generation. Existing projects open without migration.

Still deliberately excluded

Milestone 4.0I does not add multi-hero package export, installed-mod comparison, one-click mod installation, automatic mod-version bumping, cloud storage, or user accounts.
