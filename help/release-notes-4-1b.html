ES2 Hero Studio 4.1B — Hero Skill Eligibility

  • Version: 0.4.1-beta.2
  • Milestone: 4.1B
  • Project schema: 8
  • Data approach: local, read-only Endless Space 2 game data

Added

  • Hero-specific Generic, Class, and Racial eligibility.
  • Exact heroClass and affinity relationship matching from indexed HeroDefinitions.
  • Multi-affinity Racial tree support.
  • Direct-only separation for 4.1C Innate Skills.
  • Dual direct + tree handling that preserves tree eligibility.
  • Needs data for incomplete relationship evidence instead of false rejection.
  • Active-hero eligibility summary/filter in the ES2 Skill Catalog.
  • Blocking for known ineligible/direct-only tree assignments; unknown data stays non-blocking.

Preserved

Schema 8, exactly three canonical tree roles, exactly two Innate slots, lossless schema-7 migration, local/read-only indexing, and the existing compatibility editor/export path all remain intact.

Dedicated Innate authoring, the three-tree editor, full canonical-tree catalog insertion, and final schema-8 release/export readiness remain later 4.1 milestones.
